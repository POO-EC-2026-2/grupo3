# BUG-005 — Falha na atualização de instâncias do cache

**Funcionalidade:** Atualização de monstro  
**Classe:** `MonstroRepository.java`  
**Método:** `update(Monstro monstro)`  
**Classe de teste:** `MonstroRepositoryTest.java`

## Descrição

Ao atualizar um monstro utilizando uma instância diferente daquela armazenada no cache, as outras instâncias do mesmo registro permanecem com os dados antigos na lista `loadedMonstros`.

O método `update()` utiliza `dao.update(monstro)` para atualizar o registro no banco de dados, mas não sincroniza as outras instâncias do mesmo monstro presentes no cache.

**## Passos para reprodução**

1. Cadastrar um monstro.
2. Consultar o monstro pelo ID.
3. Confirmar que as duas instâncias são diferentes.
4. Modificar os atributos da instância original.
5. Executar `repository.update(monstro)`.
6. Verificar se a outra instância armazenada no cache recebeu as alterações.

**## Resultado esperado**

Todas as instâncias do mesmo registro armazenadas no cache devem refletir os dados atualizados, mantendo a consistência entre o banco de dados e o cache.

**## Resultado obtido**

O registro é atualizado corretamente no banco de dados, mas as outras instâncias do mesmo monstro presentes no cache permanecem com os dados antigos.

**## Evidências**

- A verificação `carregado != monstro` é aprovada, confirmando que são instâncias diferentes.
- A verificação dos novos atributos na instância carregada falha, confirmando que o cache não foi sincronizado.
- Uma nova consulta por ID retorna `Nome: Morcego Gigante` e `HP: 15`, confirmando que o banco de dados recebeu as alterações.
