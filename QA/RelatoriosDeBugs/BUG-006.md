# BUG-006 — Falha na atualização de instâncias do cache

**Funcionalidade:** Atualização de jogador  
**Classe:** `PlayerRepository.java`  
**Método:** `update(Player player)`  
**Classe de teste:** `PlayerRepositoryTest.java`

## Descrição

Ao atualizar um jogador utilizando uma instância diferente daquela armazenada no cache, as outras instâncias do mesmo registro permanecem com os dados antigos na lista `loadedPlayers`.

O método `update()` utiliza `dao.update(player)` para atualizar o registro no banco de dados, mas não sincroniza as outras instâncias do mesmo jogador presentes no cache.

## Passos para reprodução

1. Cadastrar um jogador.
2. Consultar o jogador pelo ID.
3. Confirmar que as duas instâncias são diferentes.
4. Modificar os atributos da instância original.
5. Executar `repository.update(player)`.
6. Verificar se a outra instância armazenada no cache recebeu as alterações.

## Resultado esperado

Todas as instâncias do mesmo registro armazenadas no cache devem refletir os dados atualizados, mantendo a consistência entre o banco de dados e o cache.

## Resultado obtido

A atualização é realizada no banco de dados, mas a outra instância do mesmo jogador presente no cache permanece com os dados antigos.

## Evidências

- A verificação `carregado != player` é aprovada, confirmando que são instâncias diferentes.
- A verificação da atualização do nome na instância carregada falha, confirmando que o cache não foi sincronizado.
- O erro apresentado no console é: `Falha: Atualização do nome da instância carregada no cache`.
