# BUG-003 — Falha na remoção de jogador do cache

**Funcionalidade:** Exclusão de jogador  
**Classe:** `PlayerRepository.java`  
**Método:** `delete(Player player)`  
**Classe de teste:** `PlayerRepositoryTest.java`

## Descrição

Ao excluir um jogador utilizando uma instância diferente daquela armazenada no cache, o registro correspondente permanece na lista `loadedPlayers`.

O método `delete()` utiliza `loadedPlayers.remove(player)`, que não reconhece outra instância do mesmo registro, pois a classe `Player` não sobrescreve `equals()`.

## Passos para reprodução

1. Cadastrar um jogador.
2. Consultar o jogador pelo ID.
3. Confirmar que as duas instâncias são diferentes.
4. Excluir o jogador utilizando a instância consultada.
5. Verificar se o jogador foi removido do cache.

## Resultado esperado

O jogador excluído deve deixar de aparecer no cache, independentemente da instância utilizada na exclusão.

## Resultado obtido

O registro é excluído corretamente do banco de dados, mas a instância original permanece na lista `loadedPlayers`.

## Evidências

- `repository.loadFromId(id)` retorna `null` após a exclusão, confirmando que o banco foi atualizado.
- A verificação `loadedPlayers.stream().noneMatch(p -> p.getId() == id)` falha, confirmando que o cache não foi atualizado.

## Status

**Corrigido**

**Foi alterado o método delete de PlayerRepository:**
- "removeIf(p -> p.getId() == player.getId())" remove do cache qualquer instância que represente o mesmo registro no banco.

- "this.loadedPlayer.getId() == player.getId()" garante que loadedPlayer também seja limpo mesmo quando a exclusão usa outra instância.
